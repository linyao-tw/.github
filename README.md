# 我們是如何走到這地步的？

![](how-did-we-get-here.webp)

這裡說明了麟曜數位工作室的歷程：

1. 2026/8/19 為了正式承接商業案件，並能夠開立統一發票供客戶核銷與報帳，以資本額 新臺幣 167,670 元於臺中市設立「麟曜數位工作室」。
  * 包含了商業名稱及所營事業預查、刻製商業大小章、申請商業設立登記、辦理營業稅籍登記、刻製統一發票專用章、申請統一發票購票證、申請工商憑證
2. 2026/8/25 學校需要一個能夠遠端控制在走廊螢幕輪播的軟體 - [HUAN 讙](https://github.com/linyao-tw/huan)
3. 2026/8/31 一套軟體要先有 Component，所以做了 Component Library 和設計規範 - [@linyao.tw/ui](https://github.com/linyao-tw/ui)
4. 2026/8/28 要做網頁服務得要有網域 - 跟 TWNIC 申請公司免費網域 linyao.tw
5. 2026/9/5 有工作室了得要先有個網站 - [linyao.tw](linyao.tw)
6. 2026/9/6 要有說明文件和開發教學，沒有好用的套件只好從頭用 Astro 寫一個 [Docs](https://github.com/linyao-tw/docs)
7. 2026/9/7 努力在找繪師畫 Logo，目前已經被「1」位繪師拒絕

10. 購買產品需要能付款 - 串接超商取貨／信用卡
11. 現在的官網只是能暫時用的，還有很多問題。像是缺少過去案例、具體得的獎項、品牌規範、還有沒有很好看。
